# ZCSS developer runbook

## Ownership

The stable input is `ZcssDesignDocument + compiler identity`; the sole output owner is the SiteCheckout compiler. Agent-authored files are `functions.php`, `zcss.design.json`, `zeroy.theme.json`, `zeroy.schema.json`, templates, and manifest-declared custom CSS. Generated CSS and its manifest are immutable ThemeArtifact bytes, never editable inputs. Live requests read only the stylesheet set pinned by one SiteRelease.

Changing a design, compiler algorithm, browser policy, token generator, or primitive definition must change the appropriate design, source, or output hash. Custom CSS is the visual implementation truth: it may freely use semantic selectors, custom properties, Grid, Flex, gradients, pseudo-elements, animation and responsive queries. It changes the ThemeArtifact and stylesheet-set hashes without impersonating a ZCSS compiler change. ZCSS owns only generated paths and the reserved `.z-*` / `--z-*` namespaces; its primitives are optional reusable defaults, never a design-style quota.

## Local verification

Use an explicitly disposable LocalWP site. Both commands replace its Connector and reset zeroY-owned tables/options/meta; the Agent acceptance also installs a deterministic ACF Pro copy and an acceptance-only machine CPT fixture. Ordinary WordPress content is not a zeroY-owned reset surface.

```bash
ZEROY_ZCSS_BROWSER_LOCALWP_PORT=10013 \
  pnpm --filter @yansircc/pi-zeroy run acceptance:zcss-browser

ZEROY_ACCEPTANCE_MODEL=k3 \
ZEROY_ZCSS_AGENT_LOCALWP_PORT=10013 \
  pnpm --filter @yansircc/pi-zeroy run acceptance:zcss-agent
```

Chromium discovery checks `ZEROY_BROWSER_EXECUTABLE`, the Playwright Chromium cache, Chrome for Testing, Google Chrome, and common Chromium paths. The Pi bundle uses Node built-ins and CDP; it does not bundle Playwright or a browser binary.

The browser gate must end with one result for every declared scenario and viewport. The Agent gate must additionally prove:

- only the four zeroY tools were callable;
- no empty-argument probe or local filesystem/source/database/SSH/WP-CLI side channel occurred;
- one valid Draft existed before the deliberate ZCSS compiler failure;
- the same Draft was repaired and activated;
- site tokens, a component-private property, custom grid, reduced-motion-safe animation, and Draft StyleSurface reuse are present;
- active proof and external checks are green.

## Failure triage

`zeroy_zcss_compile_failed` is an input-contract failure. Repair `zcss.design.json` in the same Draft using its structured field diagnostics. Namespace/reference/style failures belong to `styleSurface` and CandidateProof; repair the owning custom stylesheet, never generated bytes.

An `preview-awaiting-browser` PreviewRelease is immutable private work, not a partial deployment. Repeating Push for the same Commit resumes its exact browser challenge. Evidence is accepted only when release, ThemeArtifact, scenario set, stylesheet set, viewport set, and contrast scope all match. Browser failure leaves the ActiveRelease unchanged and the source Draft repairable.

If a PreviewRelease blocks, inspect complete `proof` rather than inferring from HTTP rendering. A proof may claim only checks it executed. `externalCheck` is a public-route witness to run after an administrator has published the exact proof-ready version; it does not replace Preview proof.

## Release gates

After the working tree is committed, run:

```bash
pnpm --filter @yansircc/pi-zeroy run repo:verify
pnpm --filter @yansircc/pi-zeroy run pi:verify
ZEROY_LOCALWP_PORT=10013 pnpm --filter @yansircc/pi-zeroy run acceptance:site-release
pnpm --filter @yansircc/pi-zeroy run acceptance:remote-only
pnpm --filter @yansircc/pi-zeroy run acceptance:agent-stage-recovery
ZEROY_ZCSS_BROWSER_LOCALWP_PORT=10013 pnpm --filter @yansircc/pi-zeroy run acceptance:zcss-browser
pnpm verify
pnpm verify:packages
pnpm release:build-candidates
pnpm verify:candidates
pnpm verify:consumers
git diff --check
```

Candidate building requires a clean committed source SHA. The candidate manifest is the only mapping from that source SHA to selected package version and exact archive integrity; never rebuild or repack a witnessed archive.
